# Techu Tate roadmap

Adapted to Lovable stack (TanStack Start + Lovable Cloud) per user approval.

## Phase 1 — Accounts + shell

- [x] Email/password sign up (username, 10+ char strong password), sign in, forgot/reset password
- [x] Profiles + roles table, auto-created on signup
- [x] English / Urdu UI with RTL
- [ ] Logout all devices, first admin account, leaked-password check

## Phase 2 — Realtime chat + media

- [x] Exact-username direct chats, groups (max 100), live messages, typing, online/last seen, read ticks
- [x] Reply, edit within 15 min, delete for everyone, paging older messages
- [ ] Block/unblock, delete for me, group member management, hide-last-seen setting
- [ ] Images, video, voice notes, files (storage + limits)
- [ ] Emoji picker, push notifications, disappearing messages

## Phase 3 — End-to-end encryption (Web Crypto)

- [ ] Identity keys, passphrase backup, per-chat AES-GCM, group keys, encrypted media, safety numbers, Security page

## Phase 4 — Admin + hardening

- [ ] Admin panel (stats, users, reports, settings, audit log), 2FA for admins
- [ ] Security review, privacy/terms pages, data export, account deletion
